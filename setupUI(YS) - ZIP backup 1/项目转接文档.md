# 智能车项目转接文档

## 一、项目概述

- **比赛**：第二十一届全国大学生智能汽车竞赛（人工智能模型组）
- **硬件**：X-01板卡(RK3588) / 香橙派5
- **任务**：4圈赛道自动驾驶（行人避让→路牌OCR→红绿灯→全域巡航）
- **虚实同步**：虚拟车(UDP 9005) + 实车(UART1串口ASCII指令)
- **定位**：ArUco定位平替官方定位模块（比赛时换官方定位）

## 二、系统架构

```
X-Verse引擎 → 共享内存(shm_ar_video) → main_control.py主循环
                                          ↓
                    ┌─────────────────────┼─────────────────────┐
                    ↓                     ↓                     ↓
              ArrowNavigator        目标检测(每2帧)       ArUco定位(UDP 9006)
              (HSV蓝色箭头导航)     (行人/car避障)        (延迟补偿65ms)
                    ↓                     ↓                     ↓
                    └─────────→ 决策融合 ←──────────────────────┘
                                    ↓
                              PD控制 + 连续前瞻减速 + 速度自适应增益
                                    ↓
                              非线性映射(|offset|^1.5)
                                    ↓
                    ┌───────────────┴───────────────┐
                    ↓                               ↓
              vcar.drive()                    控制线程(50fps)
              (虚拟车UDP 9005)                uart1.send_drive()
                                              (实车A+D+F指令)
```

### 多线程架构
- **视觉线程**（主循环）：读帧→ArrowNavigator→决策融合→更新_latest_drive（15-20fps）
- **控制线程**：50fps读_latest_drive→send_drive（offset变化时立即发，不变时100ms保活）

## 四、已完成的优化（按阶段）

### 阶段0：删除无用计算（已调好 ✅）
- `show_window=False`时跳过语义分割(NPU)和EdgeDetector(CPU)
- `cv2.waitKey`仅显示时调用
- 帧率从~10fps提升到~20fps
- 避障代码完整保留

### 阶段1：远近双带感知（已调好 ✅）
- ArrowNavigator从单质心改为**远近双带**：
  - 近带(0.65~1.0h)：横向偏差修正
  - 远带(0.40~0.65h)：前方走向预判
  - 融合：`offset = 0.5×近带 + 0.5×远带`
- **岔路检测**：近带偏移 < 远带×30% 且远带>0.08时忽略远带（防岔路误转）
- 死区0.08（abs(offset)<0.08不转向）

### 阶段2：PD控制（已调好 ✅）
- 加D项：`final_offset = offset + kd × (offset - prev_offset)`
- 砍掉base_smooth_alpha（1.0=不滤波，D项替代防抖）
- ArrowNavigator EMA alpha=0.85（减少滞后）
- 直道微调：abs(offset)<0.15时×0.6（防HSV偏差导致直道大幅偏转）
- 入弯提前转、出弯提前回正

### 阶段3：连续前瞻减速 + 速度自适应增益（已调好 ✅）
- 弯道减速从两档阶梯改为**连续函数**：`speed = max(floor, 1.0 - decel_gain × |far_offset|)`
- 用远带offset提前减速（弯前就收速）
- 速度自适应增益：`final_offset = offset × (1 + 0.3 × speed_ratio)`（高速加重转向）

### 阶段4：非线性映射（已调好 ✅）
- send_drive从线性`offset×range×3`改为非线性`|offset|^1.5×range×4`
- 小偏差细调（直道稳）、大偏差加重（弯道猛）
- servo_range=20

### 算法层6处优化（已调好 ✅）
1. EMA alpha 0.7→0.85（延迟减半）
2. offset_max_delta 0.2→0.3（入弯1帧到位）
3. 直道微调 ×0.4→×0.6（修正更快）
4. near_weight 0.7→0.5（远带占50%提前减速）
5. far_offset上升更快（alpha提升附带）
6. servo_range 16→20（急弯转得更急）

### 架构层优化（已调好 ✅）
1. **多线程控制**：控制线程50fps，视觉帧率不稳定时控制不停
2. **ArUco延迟补偿**：速度外推65ms（`pred_x = measured_x + velocity × 0.065`）

### 避障逻辑重写（已调好 ✅）
- **car避让**：检测到就向反方向转向（`-sign(obj_offset) × gain`），减速0.7
- **行人避让**：连续3帧确认才停车（防误检），远处减速0.5通过，不转向
- **起步加速**：STOP恢复后前5帧全速D9（防扭矩不足走不动）
- avoid_gain=0.4, avoid_trigger_y=0.15（提前触发）

### 其他修复（已调好 ✅）
- STARTUP模式卡死修复：arrow_valid=True直接出发（不原地对准）
- 目标检测恢复：每2帧一次（避障需要）
- OCR模型：ernie-5.0→ernie-4.5-turbo-32k（千帆平台可用模型）
- 路牌检测：目标检测优先(class=13) + 颜色检测回退
- cleanup连发S+D0×5确保停车
- 串口I/O error处理

## 七、未解决的问题

### 1. HSV检测系统性偏移（⚠️ 核心问题）
- **现象**：HSV质心有时持续偏左、有时持续偏右，导致车朝一个方向转圈
- **原因**：HSV阈值(85-125)可能检测到赛道外的干扰蓝色（场地边缘/光线反射）
- **当前缓解**：死区0.08 + 直道微调×0.6 + 岔路检测
- **根本解决**：需要看实际画面调HSV阈值，或换更鲁棒的赛道检测方法
- **排查方法**：临时设`show_window=True`，看蓝色mask覆盖情况

### 2. 冲出赛道后转圈死循环（⚠️）
- **现象**：车冲出赛道后，HSV检测到干扰蓝色，arrow_valid=True但offset持续偏一个方向，车转圈找不回来
- **原因**：arrow_valid=True不触发丢失恢复逻辑（`arrow_lost_recover_gain`）
- **可能的解决**：
  - 提高min_pixels门槛（零星蓝色不算有效）
  - 检测yaw振荡（转圈）时强制直行突破
  - 限制连续同方向偏转的帧数

### 3. 避障方向未实测确认（⚠️）
- `avoid_invert=False`：新代码避让方向是`-sign(obj_offset)`（car在右→左转）
- 需要实测确认方向是否正确，如果反了改`avoid_invert=True`

### 4. 目标检测可能误检行人（⚠️）
- 赛道上的黄色标记/物体可能被检成person(class=0)
- 当前缓解：连续3帧确认才停车
- 如果仍误检：提高person_conf_thresh(当前0.5→0.7)

### 5. servo_range=20未实测（⚠️）
- 从16加到20，如果直道摆动加大降回16
- 如果急弯还是转不过加到25

### 6. OCR路牌识别未完整实测
- 千帆API能调用成功（ernie-4.5-turbo-32k）
- 降级规则匹配已实现（否定语义理解）
- 比赛现场需确认API网络连通性

## 十、调试技巧

### 看日志判断问题
```
[VCar] DRIVE   base=+0.3 avoid=+0.000 ... spd=0.8 | arrow_valid=True near=+0.3 far=+0.2
```
- `base`：箭头导航偏移（正=右，负=左）
- `avoid`：避障偏移（0=无障碍）
- `spd`：速度比例（0=停，0.75=D6，1.0=D9）
- `near/far`：近带/远带各自偏移
- `np/fp`：近带/远带像素数（<80可能检测不可靠）
- `arrow_valid`：是否检测到蓝色赛道
- `yaw`：朝向（d=变化量，如果来回振荡=转圈）

### 常见问题
| 现象 | 原因 | 解决 |
|------|------|------|
| 车不动 | 串口没连/USB线松 | `ls /dev/ttyUSB0` + 重新插拔 |
| 车转圈 | HSV偏移/冲出赛道 | 看near/far值，调HSV阈值 |
| 直道偏转大 | HSV系统性偏差 | 调dead_zone或直道微调系数 |
| 弯道冲出 | 转向不够/速度太快 | 加servo_range或降max_duty |
| 停车不走 | 行人误检/起步扭矩不足 | 3帧确认已加+起步5帧全速 |
| STARTUP卡死 | 原地对准死循环 | 已修复(arrow_valid直接出发) |

### 关键参数调试方向
| 参数 | 调大 | 调小 |
|------|------|------|
| max_duty | 直道更快 | 直道更慢但安全 |
| servo_range | 弯道转更急 | 直道更稳 |
| steering_kd | 入弯更提前 | 直道更稳 |
| decel_gain | 弯道减速更多 | 弯道更快但风险 |
| near_weight | 更看当前位置 | 更看前方(提前转) |
| arrow_dead_zone | 直道更稳 | 小弯道更敏感 |
| avoid_gain | 避让更猛 | 避让更温和 |
