## 五、还没调好的问题

### 5.1 VL文字识别不稳定 ⚠️
- **现象**：同一路牌VL识别出不同文字（"大堵了吧"有时识别成"听析了吧"）
- **原因**：ernie-4.5-turbo-vl-32k对像素字体识别能力有限
- **影响**：文字识别错→语义判断错→方向错
- **建议**：改用两步法为主路径（qianfan-ocr文字提取更专业+ernie-5.0判断方向）

### 5.2 谐音梗路牌识别 ⚠️
- **现象**："悠邹"谐音"右走"，VL/LLM理解能力有限
- **当前**：prompt规则7+ernie-5.0，但效果不稳定
- **建议**：接受偶尔识别错误（宁可straight不要乱转），或代码层加谐音关键词匹配

### 5.3 舵机方向未确认 ⚠️
- **现象**：servo_invert=True时offset=-0.356(左转)→A110(可能右转)
- **需要确认**：画面上车实际转向方向与代码计算是否一致
- **如果方向反了**：改 `"uart1_servo_invert": False`

### 5.4 路口靠左在OCR hold 1秒后仍可能干扰 ⚠️
- **现象**：OCR hold 1秒过期后，路口靠左立即触发，可能导致偏转
- **当前**：hold 1秒+路口检测pixels>500
- **建议**：如果仍干扰，延长hold到1.5秒或去掉路口靠左逻辑

### 5.5 巡线在急弯上base偏大可能冲出 ⚠️
- **现象**：base=+0.3→final接近0.5满偏
- **当前**：speed_steer_gain=0.15降低了放大
- **建议**：如果急弯还冲出，降低servo_range或加offset上限

## 八、调试技巧

### 看日志判断问题
```
[VCar] DRIVE base=+0.300 avoid=+0.000 sign=+0.000(s) final=+0.350 spd=0.8 | arrow_valid=True near=+0.300 far=+0.200 np=25000 fp=3000 | yaw=90.0 x=+2.50 z=+3.00
```
- `base`：巡线偏移（正=右，负=左）
- `avoid`：避障偏移（0=无障碍）
- `sign`：路牌方向（s=straight, r=right）
- `final`：最终偏移
- `spd`：速度比例（0.75=D6, 1.0=D8）
- `near/far`：近带/远带偏移
- `np/fp`：近带/远带像素数（<80可能不可靠）
- `arrow_valid`：是否检测到蓝色赛道

### 路牌OCR日志
```
[Sign] 蓝块3.4% std44 白13% → 路牌！     ← 检测到路牌
[Sign] 路牌较远(blue=2.1%) → 继续靠近     ← 太远不OCR
[Sign] 检测到路牌 → 停车调用OCR            ← 停车OCR
[ERNIE-V] VL模型回复: 文字：[xxx]          ← VL识别的文字
方向：right                                ← VL判断的方向
[Sign] OCR结果 → right                     ← 最终结果
[Sign] OCR看不清 → 继续靠近再识别           ← 看不清重新靠近
[Sign] 连续3次非路牌 → 暂停检测30秒         ← 暂停检测
```

### 常见问题
| 现象 | 原因 | 解决 |
|------|------|------|
| 车不动 | 串口未连接 | `ls /dev/ttyUSB*` + `sudo chmod 666` |
| 车转圈 | HSV偏移/冲出赛道 | 看near/far值，调HSV阈值 |
| 直道偏转大 | HSV系统性偏差 | 调dead_zone或直道微调系数 |
| 弯道冲出 | 转向不够/速度太快 | 加servo_range或降max_duty |
| 路牌不检测 | std/blue_ratio不够 | 看日志的std和蓝块值 |
| OCR识别错 | VL文字识别不准 | 看VL回复的文字，考虑两步法 |
| 路口冲出 | 路口靠左干扰 | 确认OCR hold期内禁用靠左 |
| SyntaxError | 文件传输损坏 | 压缩传输+py_compile验证 |
| setup_webui解压失败 | /tmp空间不足 | `TMPDIR=~/tmp ./setup_webui` |
