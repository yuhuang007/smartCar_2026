# UART1 串口指令文档

## 1. 概述

本文档适用于工程 `E02_02_drv8701e_double_motor_contro_demo`。

当前串口功能包括：

- 双电机运行控制
- 舵机角度控制
- 编码器测速状态回传

当前工程使用 `UART1` 作为串口通信接口。

## 2. 串口参数

- 串口号：`UART1`
- 波特率：`115200`
- 数据位：`8`
- 停止位：`1`
- 校验位：`无`
- 建议发送结束符：`\r\n`

## 3. 硬件连接

- `UART1_TX -> P31`
- `UART1_RX -> P30`
- `GND -> GND`

## 4. 指令格式

- 指令采用 ASCII 字符串
- 支持大写和小写
- 每条指令建议以回车或回车换行结束
- 指令长度不能超过缓冲区限制，否则会返回错误

## 5. 指令列表

### 5.1 电机启动

- 指令：`F`
- 功能：启动电机运行
- 说明：按当前设定占空比输出

详细说明：

- `F` 指令用于使能电机输出
- 执行该指令后，程序会将电机状态置为运行
- 电机实际输出占空比由当前保存的 `Dxx` 参数决定
- 如果上一次未发送过 `Dxx`，则默认按程序内初始占空比运行
- 该指令本身不修改占空比，只负责启动

执行效果：

- 左右两路电机同时开始输出 PWM
- 输出方向由当前程序中的方向脚默认配置决定
- 串口返回当前实际启用的占空比

典型使用场景：

- 上电后先发 `D10`，再发 `F`，让电机以较低速度起转
- 调整好占空比后重复发送 `F`，可重新启动电机

注意事项：

- 建议先设置占空比，再发送 `F`
- 若直接使用较高占空比启动，电机电流冲击会更大
- `F` 只控制电机，不影响舵机角度

示例：

```text
F
```

返回：

```text
OK F duty=25%
```

### 5.2 电机停止

- 指令：`S`
- 功能：停止电机
- 说明：PWM 输出清零

详细说明：

- `S` 指令用于关闭电机 PWM 输出
- 执行后，程序会将电机运行标志清零
- 当前保存的占空比参数不会丢失，只是停止输出
- 下次再次发送 `F` 时，仍按最近一次设置的占空比运行

执行效果：

- 左右两路电机 PWM 输出关闭
- 电机进入停止状态
- 串口返回停止确认信息

典型使用场景：

- 电机运行过程中需要紧急停机
- 调整参数前先停止电机
- 调试编码器或舵机时，避免电机持续转动

注意事项：

- `S` 停止的是电机，不影响串口通信和编码器采集
- `S` 不会改变舵机当前角度

示例：

```text
S
```

返回：

```text
OK S
```

### 5.3 设置电机占空比

- 指令：`Dxx`
- 功能：设置电机 PWM 占空比
- 参数范围：`0~100`

详细说明：

- `Dxx` 用于设置电机 PWM 占空比
- 其中 `xx` 为十进制整数，占空比单位为百分比
- 占空比越大，电机平均驱动电压越高，通常转速也越高
- 指令执行后，占空比参数会立即更新
- 如果电机当前已处于运行状态，则占空比会立即生效
- 如果电机当前处于停止状态，则仅保存参数，待发送 `F` 后使用

参数说明：

- `D0`：占空比设置为 `0%`
- `D10`：占空比设置为 `10%`
- `D25`：占空比设置为 `25%`
- `D100`：占空比设置为 `100%`

执行效果：

- 修改 `motor_duty_percent` 参数
- 若电机正在运行，则电机速度会立刻发生变化
- 串口返回最新占空比

典型使用场景：

- `D10`：低速调试
- `D20`：中低速运行
- `D50`：较高速度运行测试

注意事项：

- 参数只能为数字，不能带空格或其他字符
- 参数范围超出 `0~100` 时会被判为非法命令
- 建议从小占空比开始测试，避免电机猛冲

示例：

```text
D10
D25
D50
```

返回：

```text
OK D10
OK D25
OK D50
```

### 5.4 设置舵机角度

- 指令：`Axx`
- 功能：设置舵机目标角度
- 参数范围：当前程序允许 `0~180`

详细说明：

- `Axx` 用于设置舵机目标角度
- 其中 `xx` 为十进制整数，单位为度
- 程序会根据输入角度换算成对应 PWM 脉宽输出给舵机
- 指令执行后，舵机会尝试转到目标角度
- 当前打印的 `舵机角度` 为目标角度值，不是传感器反馈角度

参数说明：

- `A90`：舵机转到中位附近
- `A60`：舵机转到较小角度
- `A120`：舵机转到较大角度

执行效果：

- 更新舵机角度参数
- 立即刷新舵机 PWM 输出
- 串口返回当前角度确认信息

典型使用场景：

- `A90`：舵机回中
- `A80`、`A100`：小范围摆动测试
- `A60`、`A120`：扩大动作范围测试

注意事项：

- 虽然程序允许 `0~180`，但实际机械结构未必支持全范围动作
- 若舵机存在机械限位，建议优先在小范围角度内调试
- 若舵机出现异响、发热或堵转，应立即减小角度范围

示例：

```text
A90
A120
A60
```

返回：

```text
OK A90
OK A120
OK A60
```

## 6. 状态回传

程序会周期性输出当前系统状态，格式如下：

```text
编码器计数=xxx 转速=xxxrpm 占空比=xx% 状态=运行/停止 舵机角度=xx
```

各字段含义如下：

- `编码器计数`：当前测速周期内采集到的编码器脉冲数
- `转速`：根据编码器计数换算得到的转速，单位为 `rpm`
- `占空比`：当前电机占空比设定值
- `状态`：`运行` 表示电机已启动，`停止` 表示电机已停止
- `舵机角度`：当前舵机目标角度

状态输出示例：

```text
编码器计数=-73 转速=-112rpm 占空比=25% 状态=运行 舵机角度=90
```

## 7. 错误返回

### 7.1 非法指令

当输入不符合定义时，返回：

```text
ERR xxx
```

示例：

```text
ERR X12
```

### 7.2 指令过长

当指令超过缓冲区长度时，返回：

```text
ERR command too long
```

## 8. 使用示例

### 8.1 电机运行示例

```text
D10
F
```

说明：

- 先设置占空比为 `10%`
- 再启动电机运行

### 8.2 电机停止示例

```text
S
```

### 8.3 舵机控制示例

```text
A90
A120
A60
```

### 8.4 综合控制示例

```text
D20
F
A90
S
```

## 9. 注意事项

- 电机运行前建议先设置合适的占空比，再发送 `F`
- 舵机角度虽然程序允许 `0~180`，但实际机械结构可能不允许全范围动作
- 若舵机存在机械限位，建议优先使用较安全角度，例如 `80~100`
- 编码器转速为带方向值，负号表示反向
- 串口助手建议开启发送新行，或手动追加回车换行

## 10. 当前支持指令汇总

```text
F        启动电机
S        停止电机
Dxx      设置电机占空比
Axx      设置舵机角度
```
