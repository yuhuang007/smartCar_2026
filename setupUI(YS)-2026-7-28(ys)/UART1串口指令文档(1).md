# UART1 串口指令文档

## 1. 文档说明

本文档适用于工程 `E02_02_drv8701e_double_motor_contro_demo`。

当前工程通过 `UART1` 实现以下功能：

- 双电机前进、倒车、停止和急停控制
- 电机占空比设置
- 舵机角度设置
- 编码器测速状态回传
- `P7.3` 按键触发串口发送脚本启动命令

本文档内容以当前 `main.c` 中的实际实现为准。

## 2. 串口参数

- 串口号：`UART1`
- 波特率：`115200`
- 数据位：`8`
- 停止位：`1`
- 校验位：`无`
- 命令结束：建议发送 `\r\n`

## 3. 硬件连接

### 3.1 串口

- `UART1_TX -> P31`
- `UART1_RX -> P30`
- `GND -> GND`

### 3.2 编码器

- `ENC_PULSE -> P04`
- `ENC_DIR -> P53`
- `VCC -> 3.3V`
- `GND -> GND`

### 3.3 舵机

- `SERVO_PWM -> P33`
- `VCC -> 舵机电源`
- `GND -> GND`

### 3.4 按键

- `KEY_IN -> P73`
- `按键另一端 -> GND`
- 输入模式：内部上拉输入
- 有效电平：低电平按下有效

## 4. 指令格式

- 指令采用 ASCII 字符串
- 支持大写和小写
- 每条指令建议带回车或回车换行结束
- 当前支持的命令有：`F`、`S`、`Dxx`、`Axx`、`B`、`E`
- 指令缓冲区长度为 `16` 字节，超出会返回错误
- 除了串口接收指令外，代码还支持 `P73` 按键主动通过串口发送脚本命令给上位机

## 5. 指令总览

| 指令 | 功能 | 参数 | 示例 |
| --- | --- | --- | --- |
| `F` | 前进运行 | 无 | `F` |
| `S` | 普通停止 | 无 | `S` |
| `Dxx` | 设置电机占空比 | `0~100` | `D10` |
| `Axx` | 设置舵机角度 | `0~180` | `A90` |
| `B` | 倒车运行 | 无 | `B` |
| `E` | 急停刹车 | 无 | `E` |

## 6. 指令详细说明

### 6.1 `F` 前进运行

- 功能：让电机以前进方向运行
- 参数：无
- 方向行为：将 `motor_direction` 设为前进方向
- 输出行为：将 `motor_enable` 置为使能，并按当前占空比输出 PWM
- 依赖参数：前进运行时的占空比由最近一次 `Dxx` 设置决定

执行效果：

- 左右电机按前进方向输出
- 如果之前已经设置过占空比，则直接按该占空比运行
- 如果未重新设置占空比，则使用当前保存值

典型用法：

```text
D10
F
```

返回示例：

```text
OK F duty=10%
```

注意事项：

- `F` 只改变电机方向和运行状态，不改变舵机角度
- 建议先用 `Dxx` 设置好占空比，再执行 `F`
- 若车辆实际前进方向与预期不一致，需要检查电机接线或方向脚极性

### 6.2 `S` 普通停止

- 功能：普通停机
- 参数：无
- 方向行为：不改变当前方向状态
- 输出行为：将 `motor_enable` 清零，PWM 输出变为 0

执行效果：

- 电机停止输出
- 小车会因惯性产生一定滑行
- 不执行反向制动

典型用法：

```text
S
```

返回示例：

```text
OK S
```

注意事项：

- `S` 属于普通停机，不是急停
- 地面跑动时，执行 `S` 后车辆可能还会继续向前或向后滑行一小段
- `S` 不会修改当前占空比参数，也不会改变舵机角度

### 6.3 `Dxx` 设置电机占空比

- 功能：设置电机输出占空比
- 参数范围：`0~100`
- 参数格式：`D` 后直接跟十进制数字，不允许空格

参数说明：

- `D0`：设置为 `0%`
- `D10`：设置为 `10%`
- `D25`：设置为 `25%`
- `D100`：设置为 `100%`

执行效果：

- 更新 `motor_duty_percent`
- 如果电机当前正在运行，则新占空比立即生效
- 如果电机当前处于停止状态，则仅保存参数，等下次 `F` 或 `B` 时使用

典型用法：

```text
D10
F
```

```text
D20
B
```

返回示例：

```text
OK D10
OK D20
```

注意事项：

- 参数只能是数字
- 超过 `0~100` 范围会被判为非法命令
- 占空比增大后，车辆速度和惯性都会增大，急停参数可能需要同步重新调试

### 6.4 `Axx` 设置舵机角度

- 功能：设置舵机目标角度
- 参数范围：`0~180`
- 参数格式：`A` 后直接跟十进制数字

参数说明：

- `A90`：舵机回中附近
- `A60`：较小角度
- `A120`：较大角度

执行效果：

- 更新 `servo_angle`
- 立即刷新舵机 PWM 输出
- 舵机尝试转到指定目标角度

典型用法：

```text
A90
A120
```

返回示例：

```text
OK A90
OK A120
```

注意事项：

- 当前打印的舵机角度是目标角度，不是反馈角度
- 虽然程序允许 `0~180`，但实际机械结构未必支持全行程
- 若舵机出现堵转、异响或明显发热，应缩小角度范围

### 6.5 `B` 倒车运行

- 功能：让电机以倒车方向运行
- 参数：无
- 方向行为：将 `motor_direction` 设为倒车方向
- 输出行为：将 `motor_enable` 置为使能，并按当前占空比输出 PWM

执行效果：

- 左右电机按倒车方向输出
- 占空比沿用当前 `Dxx` 设置值

典型用法：

```text
D10
B
```

返回示例：

```text
OK B duty=10%
```

注意事项：

- 第一次测试倒车建议从 `D10` 这类低占空比开始
- 如果车辆倒车方向与预期相反，需要检查电机接线或方向定义
- `B` 不影响舵机当前角度

### 6.6 `E` 急停刹车

- 功能：执行急停
- 参数：无
- 当前实现方式：两段反向制动

当前代码中的急停参数为：

- 第一段强刹：`28% / 60ms`
- 第二段弱刹：`10% / 40ms`

执行逻辑：

1. 如果电机当前未运行，则直接返回
2. 先按当前反方向输出第一段强刹脉冲
3. 再按当前反方向输出第二段弱刹脉冲
4. 最后关闭 PWM，电机进入停止状态

执行效果：

- 比 `S` 更适合车辆跑动时快速停车
- 用于减小地面惯性带来的滑行距离
- 刹车力度与车辆方向、占空比和地面摩擦都有关系

典型用法：

```text
D10
F
E
```

```text
D10
B
E
```

返回示例：

```text
OK E brake1=28% 60ms brake2=10% 40ms
```

注意事项：

- `E` 是急停，不是普通停止
- 如果占空比较大，当前固定急停参数可能不一定覆盖所有速度范围
- 若刹车后仍有明显滑行，需要继续调大强刹时间或强刹占空比
- 若刹车后出现反冲或回弹，需要减小强刹参数
- 当前前进和倒车方向的最佳急停参数可能并不一致

### 6.7 `P73` 按键触发串口发送 `RUN`

- 功能：通过硬件按键主动向上位机发送一条脚本运行命令
- 触发引脚：`P73`
- 触发条件：按键按下时输入为低电平
- 当前发送内容：`RUN\r\n`

当前代码中的按键相关参数为：

- 按键引脚：`P73`
- 按键有效电平：低电平
- 按键释放电平：高电平
- 消抖时间：`20ms`
- 发送字符串：`RUN\r\n`

执行逻辑：

1. `P73` 配置为内部上拉输入
2. 默认松开状态为高电平
3. 检测到由高电平变为低电平时，先延时 `20ms` 消抖
4. 消抖后若仍为低电平，则通过 `UART1` 发送 `RUN\r\n`
5. 只有按键重新释放回高电平后，下一次按下才会再次发送

执行效果：

- 单次按下按键，会向上位机发送一条：

```text
RUN
```

- 适合用来触发上位机启动脚本、运行任务或执行预设动作
- 长按按键不会连续重复发送，避免串口刷屏

典型用法：

- 上位机监听串口，收到 `RUN` 后启动对应脚本
- 小车本体按下按键后，通知上位机进入某个运行流程

启动提示：

程序上电后会打印一行按键功能提示：

```text
key ready: P73 low -> send RUN
```

注意事项：

- 按键一端接 `P73`，另一端接 `GND`
- 当前按键发送的是固定字符串 `RUN\r\n`
- 如果后续需要改成别的命令，只需修改代码中的 `KEY_UART_COMMAND`
- 该功能是单片机主动发串口给上位机，不是上位机发命令给单片机
- 若上位机脚本对大小写敏感，请保持当前 `RUN` 不变

## 7. 状态回传说明

程序会周期性打印当前状态，格式如下：

```text
编码cnt=xxx 转速=xxxrpm 占空比=xx% 状态=运行/停止 方向=前进/倒车 舵机角度=xx
```

字段含义：

- `编码cnt`：当前测速周期内采集到的编码器脉冲数
- `转速`：根据编码器计数换算出的转速，单位为 `rpm`
- `占空比`：当前电机占空比设定值
- `状态`：`运行` 或 `停止`
- `方向`：`前进` 或 `倒车`
- `舵机角度`：当前舵机目标角度

状态示例：

```text
编码cnt=-554 转速=-852rpm 占空比=10% 状态=运行 方向=前进 舵机角度=90
```

说明：

- 转速为负通常表示一个方向，为正表示另一个方向
- 正负号用于区分方向，不代表故障

## 8. 错误返回

### 8.1 非法指令

当输入命令不符合当前支持格式时，返回：

```text
ERR xxx
```

示例：

```text
ERR X12
```

### 8.2 指令过长

当输入指令超过缓冲区长度时，返回：

```text
ERR command too long
```
